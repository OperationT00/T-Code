# v1.0.0 - 产品化发布

## 当时的问题

核心 Agent 能力已经完整，但启动、交互、诊断、恢复和客户端边界仍需要产品化整理。

## 设计选择

保留 Java 作为 Core Runtime，逐步拆分交互层；同时提升终端体验，并为独立客户端提供 Runtime API。

## 实现结果

- inline TUI 与大写 `T` logo。
- LSP 诊断和 Side-Git 快照。
- Prompt 分层、Runtime API 和图片输入。
- TypeScript 薄客户端。
- 公开品牌统一为 `t-code v1.0.0`。

## 下一步

继续增强 MCP OAuth、sampling、recovery，并在后续版本中逐步迁移兼容标识和包名。
