# v0.3.0 - RAG

> 历史记录：RAG 曾作为 v0.3.0 的语义检索方案交付；当前核心运行时已移除 RAG 索引和 `/index`、`/search`、`/graph` 命令，代码理解默认使用 `glob_files`、`grep_code`、`read_file`、`execute_command` 与 LSP 诊断。

## 当时的问题

文件名和关键字搜索适合精确定位，但自然语言问题和跨模块理解仍然困难。

## 设计选择

加入代码切片、Embedding、向量存储和语义检索。RAG 是辅助路径，不替代 `glob_files`、`grep_code` 和 `read_file`。

## 实现结果

- `CodeChunker` 切分源码。
- `CodeIndex` 建立索引。
- `VectorStore` 保存检索数据。
- Embedding 不可用时仍保留关键词索引。

## 下一步

降低复杂任务中多个工具调用的等待时间。
